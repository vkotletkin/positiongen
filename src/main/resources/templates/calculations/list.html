What the parameters do

Each request runs FRACTALRABBIT with the values in the form. The generator itself is unchanged.

Space dimension
Dimension of the generated place coordinates. The map draws only the first two axes. It must be greater than the fractal dimension. Uploaded places are always two-dimensional.
Fractal dimension
How tightly places clump. A smaller value packs them into tighter groups. A value closer to the space dimension spreads them more evenly.
Places file
Optional CSV of your own places. The route generator then walks these places instead of building a fractal set. Columns are latitude, then longitude. Latitude is y, the north-south axis. Longitude is x, the east-west axis.
Number of places
How many locations are generated when no places file is uploaded. More places make the routes denser and the calculation slower. An uploaded file sets this count itself.
Travelers
How many people are simulated. Companions share one route; everyone else gets a route of their own.
Companions on one route
A random group of this size follows the same sequence of places. The finished calculation lists their ids. The count cannot exceed the number of travelers. Their report times stay independent unless companions travel together.
Companions travel together
When checked, the companions keep the same places and the same report schedule. At each place their times differ by at most the time window, 15 minutes by default. When unchecked, companions still share the route, and each draws their own report times.
Observation window
Whole days in which reports may fall. Travel time is subtracted first. If the window is shorter than the trip, that traveler produces no reports.
Mean report count
Average number of reports per traveler. Each traveler draws a Poisson count around this integer, so the actual number varies.
New-cluster rate
While places are built, the rate at which the next place starts a new clump at the origin instead of attaching near an existing place. Higher values make more separate clusters. Zero keeps growing the clusters already formed. Ignored when a places file is uploaded.
Distance exponent
How strongly a step prefers nearby places. The rate toward another place is its distance raised to this power. A more negative value, such as −4 instead of −2, makes long jumps rare. A positive value prefers distant places.
Speed limit
Maximum speed in kilometers per hour. A lower limit makes each hop take longer, so more of the observation window is spent traveling and fewer reports fit.
Kilometers per model unit
Converts one abstract distance unit into kilometers. A larger value spreads the tracks farther on the map and makes the same hops take longer.
Mean trajectory length
Average number of stops on a route, drawn from a Poisson distribution. Longer routes visit more places.
Mean exploration parameter
Average eagerness to visit a place not seen yet. A higher value covers more new places. A lower value loops among places already visited.
Pareto lower bound
Shortest allowed gap between reports, as a fraction of the time left after travel. The upper cutoff is 1. A smaller bound lets reports bunch into tighter bursts.
Pareto tail
Shape of the gaps between reports. It must be less than −1. Closer to −1, long silences are more common and reports arrive in sharper bursts. A more negative value makes the gaps more even.

Calculation is FRACTALRABBIT, R. W. R. Darling. The generator algorithm is unchanged.
